Clave de Deepgram

Para saber quién dice qué, el audio pasa por Deepgram, un servicio que transcribe el bahasa y separa las voces. La traducción la sigue haciendo Claude con tu clave de siempre.

  1. Crea una cuenta en deepgram.com. Las cuentas nuevas traen crédito gratis.
  2. Entra a API Keys › Create a New API Key, copia la clave y pégala aquí.
