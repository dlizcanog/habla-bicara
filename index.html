Tu clave de Claude

Las traducciones las hace Claude con tu propia clave de API. Se guarda solo en este teléfono, nunca en la página ni en GitHub.

  1. Entra a console.anthropic.com › API Keys › Create Key. Ponle un nombre como habla-bicara.
  2. Copia la clave (empieza por sk-ant-) y pégala aquí.

Cada frase cuesta una fracción de centavo con el modelo rápido. Te conviene ponerle un límite de gasto a la cuenta en la consola.
